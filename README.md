# King Arthur's Family Tree

## Problem Statement
This project is based on the "Family Tree" problem set on the intergalactic planet of Lengaburu. The core characters are King Arthur, Queen Margaret, and their descendants. King Arthur, the emperor of Lengaburu, has ruled the planet for the last 350 years (owing to the long lifespans of Lengaburu's inhabitants). 

The objective of this application is to model this family tree and process various relationship queries and updates via input commands.

## Getting Started
To execute the application and build the family tree, you need to pass the input text file containing the execution commands. I have provided the file which is named as king_arthur_family.txt
